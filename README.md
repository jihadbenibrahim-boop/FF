# أسرار الوادي المنسي

لعبة مغامرة ثلاثية الأبعاد تعمل على الحاسوب والهاتف.

## التشغيل

افتح `index.html` مباشرة، أو شغّل خادمًا محليًا:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## التحكم

- الهاتف: أزرار الأسهم أسفل الشاشة، واسحب لتدوير الكاميرا.
- الحاسوب: `WASD` أو الأسهم للحركة، والفأرة للدوران.
- اجمع الشظايا الثماني وتجنب الحارس والصخور خلال 90 ثانية.
