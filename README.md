# أسرار الوادي المنسي

لعبة مغامرة ثلاثية الأبعاد باللغة العربية، تعمل مباشرة في المتصفح باستخدام Three.js.

## التشغيل

افتح `index.html`، أو شغّل خادمًا محليًا من مجلد المشروع:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.
