# مغامرة الكون الثلاثية

لعبة ثلاثية الأبعاد تعمل في المتصفح، مبنية بـ Three.js وJavaScript وCSS.

## التشغيل

افتح `index.html` مباشرة، أو شغّل خادمًا محليًا:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## التحكم

- **WASD** أو مفاتيح الأسهم: الحركة
- **الفأرة + السحب**: تدوير الكاميرا
- اجمع الكرات الذهبية الثمانية وتجنب الصخور
